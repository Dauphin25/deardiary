URL სახელმძღვანელო  ·  URL Reference Guide

Django 5.2  |  Python 3.11  |  2025

პირობითი ნიშნები: ყველა — ავტორიზაცია არ სჭირდება ავტ. — შესული მომხმარებელი მფლობელი — მხოლოდ ჩანაწერის შემქმნელი Staff — Django ადმინი <param> URL-ის პარამეტრი
BASE URL:  http://localhost:8000   —   ყველა მისამართი ემატება ამ Base URL-ს. მაგ: /users/login/ → http://localhost:8000/users/login/

●  ადმინ პანელი  /  Admin Panel

URL მეთოდი აღწერა წვდომა
/admin/ GET Django-ს ადმინ პანელი — ყველა ჩანაწერის მართვა Staff
/ckeditor/ GET POST CKEditor-ის ფაილების ატვირთვა ავტ.

●  მთავარი გვერდები  /  Pages

URL მეთოდი აღწერა წვდომა
/ GET მთავარი გვერდი — სიახლეები, ლიდერბორდი, პროფილის ბარათი ყველა
/<slug>/ GET სტატიკური CMS გვერდის ნახვა slug-ით ყველა
/share-card/<question_set_id>/ GET QR კოდის + Share Card-ის PNG გადმოტვირთვა ავტ.

●  მომხმარებლები  /  Users  ( /users/ )

URL მეთოდი აღწერა წვდომა
/users/register/ GET POST GET — რეგისტრაციის ფორმა
POST — ახალი ანგარიშის შექმნა (სახელი, ელ-ფოსტა, პაროლი) 		ყველა
/users/login/ GET POST GET — შესვლის ფორმა
POST — ავტორიზაცია (username + password) 		ყველა
/users/logout/ POST სისტემიდან გასვლა — სესიის წაშლა ავტ.
/users/profile/ GET პირადი გვერდი — სტატისტიკა, შეტყობინებები, გეგმა ავტ.
/users/upgrade/ POST უფასო გეგმიდან Premium-ზე გადასვლა ავტ.
/i18n/set_language/ POST ინტერფეისის ენის შეცვლა (ქართული / English / Deutsch / Русский) ყველა

●  დღიური  /  Diary  ( /diary/ )

URL მეთოდი აღწერა წვდომა
დღიურის მართვა
/diary/ GET ჩემი ყველა დღიურის სია ავტ.
/diary/create/ GET POST GET — ახალი დღიურის ფორმა
POST — დღიურის შენახვა (სათაური, სტილი, UUID) 		ავტ.
/diary/my-question-set/<slug>/ GET POST GET — დღიურის ნახვა (კითხვები, სტატისტიკა)
POST — ახალი კითხვის დამატება 		მფლობელი
/diary/my-question-set/<slug>/delete/ POST დღიურის სრულად წაშლა ყველა კითხვასთან ერთად მფლობელი
გაზიარება და შევსება
/diary/answer/share/<uuid>/ GET POST GET — დღიურის შევსების ფორმა (გაზიარებული ლინკი)
POST — პასუხების გაგზავნა + შეტყობინების შექმნა 		ავტ.
პასუხების ნახვა
/diary/my-responses/ GET ჩემი ყველა დღიური — რამდენი პასუხია თითოეულზე ავტ.
/diary/responses/<pk>/ GET კონკრეტული დღიურის ყველა პასუხი (მომხმარებლების სია) მფლობელი
/diary/response/<session_id>/ GET ერთი მომხმარებლის პასუხების სრული ნახვა მფლობელი
/diary/response/<session_id>/download/ GET პასუხის PDF-ად გადმოტვირთვა (Playwright-ით გენერირებული) მფლობელი
/diary/fetch_responses/ GET პასუხების სია JSON ფორმატში (AJAX მოთხოვნებისთვის) ავტ.
კითხვების მართვა
/diary/question/<pk>/edit/ GET POST GET — კითხვის რედაქტირების ფორმა
POST — ცვლილებების შენახვა 		მფლობელი
/diary/question/<pk>/delete/ POST კითხვის წაშლა დღიურიდან მფლობელი
